# Мой мир

Персональный статический dashboard Дэна. Работает без сервера и готов для GitHub Pages.

## Возможности
- адаптивный интерфейс для ПК и iPhone;
- тёмная/светлая тема;
- главная панель с целями, планами, финансами и работой;
- интерактивные цели с сохранением прогресса;
- локальный учёт доходов и расходов;
- календарь с отметками рабочих дней;
- разделы работы, игр, техники, здоровья и заметок;
- заметки и настройки сохраняются через `localStorage`;
- PWA manifest для добавления сайта на домашний экран iPhone;
- без сборщика и зависимостей: достаточно открыть `index.html` или разместить репозиторий на GitHub Pages.

## GitHub Pages
1. Создай новый публичный репозиторий.
2. Загрузи все файлы из этой папки, сохрани структуру `assets/`.
3. Открой **Settings → Pages**.
4. В разделе Source выбери **Deploy from a branch**.
5. Выбери `main` и `/ (root)`.
6. Сохрани настройки и открой выданный GitHub Pages адрес.

## Важно
Данные целей, финансовых операций и заметок хранятся только в браузере текущего устройства. Это сознательная особенность статической версии: никакого сервера, никакой базы данных, никакого загадочного места, куда утекают твои заметки.

## Структура
- `index.html` — страницы и разметка;
- `style.css` — дизайн и адаптив;
- `app.js` — интерактивность и локальное хранение;
- `manifest.json` — PWA-настройки;
- `assets/hero.png` — атмосферный фон;
- `assets/favicon.svg` — иконка сайта.
